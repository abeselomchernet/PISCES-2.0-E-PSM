| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

---

## Reporting a Vulnerability

Security and integrity are paramount for institutional financial systems. If you discover a security vulnerability within Berhane OS, please report it responsibly:

1. **Do not** open a public issue.
2. Email details to: `berhaneunity@gmail.com`
3. Include:
   - Description of the vulnerability
   - Steps to reproduce or proof-of-concept
   - Potential impact on underwriting data or clearing logic
4. You will receive an acknowledgment within 48 hours.
